Checkpoint Final: Validación Integral de Datos COCODI
Fecha: 9 de Octubre de 2025
Este documento certifica la finalización exitosa del proceso de validación y limpieza de los datos fundacionales para el proyecto COCODI. El ecosistema de datos resultante está íntegro, sincronizado y es consistente con todas las reglas de negocio definidas.

El Proceso de Validación ⚙️
Nuestro trabajo se dividió en tres fases principales:

Fase 1: Consolidación de Datos Maestros. Se validó el init.sql inicial contra un archivo de negocio, resultando en una base de 69 instituciones y 17 tipos de órgano con datos corregidos y estandarizados. La acción más crítica fue la reclasificación de SESNA para alinearla con su realidad operativa.

Fase 2: Validación de Datos Históricos (Bitácora de Sesiones). Se procesó un archivo de 397 sesiones. El análisis reveló inconsistencias que fueron resueltas mediante el mapeo de instituciones obsoletas (DICONSA, LICONSA), la eliminación de 2 registros corruptos y, fundamentalmente, la expansión de nuestras reglas de negocio al autorizar 26 nuevos vínculos basados en la data histórica. El resultado fue una bitácora limpia de 395 registros válidos.

Fase 3: Validación y Enriquecimiento de Datos (Bitácora de Informes). Se procesó un archivo de 105 informes. Se resolvió la omisión de datos del órgano emisor aplicando una regla de inferencia clave. El resultado fue una bitácora de 105 informes 100% válidos y enriquecidos con el órgano correspondiente.

La Lógica de Negocio Consolidada ⚖️
Este es el conjunto final de reglas que gobierna los datos de COCODI:

Marco Legal:

Toda Entidad debe tener un Órgano de Gobierno (o subtipo).

El COCODI es el órgano de control interno institucional por defecto.

Reglas de Negocio Refinadas:

Regla de Órgano Principal: Toda institución debe tener al menos un vínculo (institución, órgano). Si las reglas explícitas no le asignan uno, se le asigna un COCODI por defecto.

Regla de Inferencia para Informes: Para determinar el órgano emisor de un informe, se aplica que:

RAAD ⇒ id_tipo_organo = 1 (COCODI)

Informe de Autoevaluación o Estados Financieros ⇒ id_tipo_organo = 2 (Órgano de Gobierno)

Excepciones Validadas: Se reconoce y permite que:

SESNA, a pesar de su naturaleza, opera como una Entidad y por tanto tiene un Órgano de Gobierno.

Existen 9 instituciones Desconcentradas que, por su operación, cuentan con un Órgano de Gobierno de forma excepcional y válida.
